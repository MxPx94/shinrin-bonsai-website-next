# Shinrin Bonsai — Next.js

Next.js-Version der ursprünglichen deutschsprachigen Shinrin-Bonsai-Website. Gestaltung, Farbwelt, Typografie und Satzbau orientieren sich am HTML-Original.

## Starten

```bash
npm run dev
```

Danach ist die Website unter http://localhost:3000 erreichbar.

## Seiten

- `/` Startseite
- `/geschichte` Geschichte / Über uns
- `/produkte` Produkte mit Kategorie-Filter
- `/kontakt` Kontaktformular
- `/impressum` Rechtliche Pflichtangaben

Die Originalbilder liegen unter `public/assets/images` und können wie bisher durch Dateien mit denselben Namen ersetzt werden.
